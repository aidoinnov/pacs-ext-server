## 🔍 1. S3 Service 분석

### 1.1 기존 구현 확인

**파일**: `pacs-server/src/infrastructure/external/s3_object_storage_service.rs`

**기존 메서드**:
- ✅ `generate_upload_url()` - Signed URL 생성
- ✅ `generate_download_url()` - 다운로드 URL 생성
- ✅ `delete_file()` - **단일 파일 삭제** (GC에서 사용 가능!)
- ✅ `file_exists()` - 파일 존재 확인
- ✅ `list_files()` - 파일 목록 조회
- ✅ `copy_file()` - 파일 복사
- ✅ `move_file()` - 파일 이동

### 1.2 추가 필요 메서드

**배치 삭제 메서드** (선택사항):
```rust
/// 여러 파일을 한 번에 삭제 (S3 DeleteObjects API 사용)
async fn delete_files_batch(
    &self, 
    file_paths: Vec<String>
) -> Result<BatchDeleteResult, ObjectStorageError>;
```

**이유**:
- 현재 `delete_file()`로 개별 삭제 가능
- 배치 삭제는 성능 최적화용 (선택사항)
- **Phase 1에서는 `delete_file()` 사용, Phase 2에서 배치 삭제 추가**

### 1.3 재사용 방법

**GC Service에서 사용**:
```rust
use crate::application::services::ObjectStorageService;

pub struct GcServiceImpl {
    gc_repository: Arc<dyn GcRepository>,
    gc_log_repository: Arc<dyn GcLogRepository>,
    object_storage: Arc<dyn ObjectStorageService>,  // ✅ 기존 S3 Service 재사용
}

impl GcServiceImpl {
    async fn cleanup_failed_snapshots(&self, ...) -> Result<Vec<GcResult>, ServiceError> {
        // ...
        for annotation in annotations {
            if let Some(key) = &annotation.snapshot_image_key {
                // ✅ 기존 delete_file() 메서드 사용
                self.object_storage.delete_file(key).await?;
            }
        }
        // ...
    }
}
```

## 🏗️ 2. Annotation Entity 분석

### 2.1 기존 필드 확인

**파일**: `pacs-server/src/domain/entities/annotation.rs`

**스냅샷 관련 필드** (모두 존재 ✅):
```rust
pub struct Annotation {
    pub id: i32,
    // ... 기타 필드 ...
    
    /// 스냅샷 이미지의 S3 object key
    pub snapshot_image_key: Option<String>,
    
    /// 스냅샷 업로드 상태
    pub snapshot_status: Option<SnapshotUploadStatus>,
    
    /// 스냅샷 업로드 완료 시간
    pub snapshot_uploaded_at: Option<DateTime<Utc>>,
    
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}
```

### 2.2 SnapshotUploadStatus ENUM

**파일**: `pacs-server/src/domain/entities/annotation.rs`

```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize, sqlx::Type)]
#[sqlx(type_name = "snapshot_upload_status", rename_all = "lowercase")]
pub enum SnapshotUploadStatus {
    Pending,    // URL 생성됨, 업로드 대기 중
    Uploading,  // 업로드 진행 중
    Completed,  // 업로드 완료
    Failed,     // 업로드 실패
}
```

**GC에서 사용할 상태**:
- ✅ `Pending` - Job A에서 타임아웃 처리
- ✅ `Failed` - Job B에서 S3 삭제

### 2.3 재사용 방법

**GC Repository에서 사용**:
```rust
use crate::domain::entities::annotation::{Annotation, SnapshotUploadStatus};

impl GcRepositoryImpl {
    async fn find_pending_snapshots(&self, grace_days: i32, batch_size: i32) 
        -> Result<Vec<Annotation>, sqlx::Error> 
    {
        sqlx::query_as::<_, Annotation>(
            r#"
            SELECT * FROM annotation_annotation
            WHERE snapshot_status = $1
              AND updated_at < NOW() - INTERVAL '1 day' * $2
            LIMIT $3
            "#
        )
        .bind(SnapshotUploadStatus::Pending)  // ✅ 기존 ENUM 재사용
        .bind(grace_days)
        .bind(batch_size)
        .fetch_all(self.pool.as_ref())
        .await
    }
}
```

## ⚠️ 3. ServiceError 분석

### 3.1 기존 Error 타입 확인

**파일**: `pacs-server/src/domain/mod.rs`

```rust
#[derive(Debug, Clone)]
pub enum ServiceError {
    NotFound(String),
    AlreadyExists(String),
    ValidationError(String),
    ValidationFailed(String),
    DatabaseError(String),           // ✅ DB 에러
    Unauthorized(String),
    Forbidden(String),
    ExternalServiceError(String),    // ✅ S3 에러 변환 가능
    VersionConflict { ... },
}
```

**GC에서 필요한 에러**:
- ✅ `DatabaseError` - DB 쿼리 실패
- ✅ `ExternalServiceError` - S3 삭제 실패

### 3.2 ObjectStorageError 변환

**파일**: `pacs-server/src/application/services/object_storage_service.rs`

```rust
#[derive(Debug, thiserror::Error)]
pub enum ObjectStorageError {
    #[error("S3 operation failed: {0}")]
    S3Error(String),  // ✅ S3 에러
    
    #[error("Configuration error: {0}")]
    ConfigError(String),
    
    #[error("File not found: {0}")]
    FileNotFound(String),
    
    // ...
}
```

### 3.3 재사용 방법

**GC Service에서 에러 변환**:
```rust
impl GcServiceImpl {
    async fn cleanup_failed_snapshots(&self, ...) -> Result<Vec<GcResult>, ServiceError> {
        // ...
        match self.object_storage.delete_file(key).await {
            Ok(_) => {
                // 성공 로그
            }
            Err(e) => {
                // ✅ ObjectStorageError → ServiceError 변환
                let error_msg = format!("S3 delete failed: {}", e);
                return Err(ServiceError::ExternalServiceError(error_msg));
            }
        }
        // ...
    }
}
```
