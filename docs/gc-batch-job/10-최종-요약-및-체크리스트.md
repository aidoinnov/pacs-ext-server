# 10. 최종 요약 및 체크리스트

> **목적**: GC Batch Job 구현 전체 요약 및 실행 가능한 체크리스트

---

## 📊 프로젝트 개요

### 목표
- **PENDING 상태 타임아웃 처리** (Job A) - 3일 이상 pending → failed
- **FAILED 상태 스냅샷 정리** (Job B) - 7일 이상 failed → S3 삭제

### 아키텍처
```
gc_runner (Binary)
    ↓
GcService (Business Logic)
    ↓
GcRepository + GcLogRepository (DB Query)
    ↓
PostgreSQL + S3
```

### 핵심 설계 원칙
- ✅ 단일 책임 원칙 (SRP)
- ✅ 계층 분리 (Domain, Repository, Service, Binary)
- ✅ 의존성 주입 (DI)
- ✅ 에러 처리 일관성
- ✅ 기존 코드베이스 패턴 준수

### Phase 2: 배치 삭제 구현 (선택사항)

#### 1. ObjectStorageService에 배치 삭제 메서드 추가

**경로**: `pacs-server/src/application/services/object_storage_service.rs`

```rust
#[async_trait]
pub trait ObjectStorageService: Send + Sync {
    // ... 기존 메서드 ...

    /// 여러 파일을 한 번에 삭제 (S3 DeleteObjects API 사용)
    async fn delete_files_batch(
        &self,
        file_paths: Vec<String>,
    ) -> Result<BatchDeleteResult, ObjectStorageError>;
}

#[derive(Debug, Clone)]
pub struct BatchDeleteResult {
    pub deleted: Vec<String>,
    pub errors: Vec<(String, String)>,  // (file_path, error_message)
}
```

#### 2. S3ObjectStorageService에 구현 추가

**경로**: `pacs-server/src/infrastructure/external/s3_object_storage_service.rs`

```rust
use aws_sdk_s3::types::{Delete, ObjectIdentifier};

#[async_trait]
impl ObjectStorageService for S3ObjectStorageService {
    // ... 기존 메서드 ...

    async fn delete_files_batch(
        &self,
        file_paths: Vec<String>,
    ) -> Result<BatchDeleteResult, ObjectStorageError> {
        // S3 DeleteObjects API는 최대 1000개까지 지원
        let objects: Vec<ObjectIdentifier> = file_paths
            .iter()
            .map(|path| {
                ObjectIdentifier::builder()
                    .key(self.generate_object_key(path))
                    .build()
                    .unwrap()
            })
            .collect();

        let delete = Delete::builder()
            .set_objects(Some(objects))
            .build()
            .map_err(|e| ObjectStorageError::S3Error(e.to_string()))?;

        let result = self.client
            .delete_objects()
            .bucket(&self.bucket_name)
            .delete(delete)
            .send()
            .await
            .map_err(|e| ObjectStorageError::S3Error(e.to_string()))?;

        // 결과 파싱
        let deleted = result.deleted()
            .iter()
            .filter_map(|d| d.key().map(|k| k.to_string()))
            .collect();

        let errors = result.errors()
            .iter()
            .filter_map(|e| {
                let key = e.key()?.to_string();
                let message = e.message()?.to_string();
                Some((key, message))
            })
            .collect();

        Ok(BatchDeleteResult { deleted, errors })
    }
}
```

### 2. 수동 복구 스크립트
```bash
#!/bin/bash
# manual_gc_recovery.sh

# 실패한 로그 조회
psql -U pacs_user -d pacs_db -c "
SELECT annotation_id, snapshot_image_key, error_message
FROM gc_deletion_log
WHERE status = 'failed'
  AND deleted_at > NOW() - INTERVAL '1 day'
ORDER BY deleted_at DESC;
"

# 수동으로 재실행
kubectl create job --from=cronjob/gc-job-b-cleanup-failed gc-manual-recovery -n pacs-system
```
