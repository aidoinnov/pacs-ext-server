# Subject 자동 생성 - 마이그레이션 가이드

## 📋 개요

기존에 프로젝트에 할당된 Study들에 대해 Subject를 자동으로 생성하는 마이그레이션 도구입니다.

## 🎯 목적

- 기존 Study에 Subject 자동 생성
- Patient ID 기반 그룹핑
- Patient ID가 없는 경우 자동 코드 생성 (A-001, A-002, ...)

## 📁 파일 위치

```
pacs-server/scripts/
├── migrate_subjects.py          # 메인 스크립트
└── README.md                    # 사용 가이드
```

## 📊 처리 로직

### 1. 프로젝트별 처리
```python
for project in projects:
    # 1. 프로젝트에 할당된 Study 조회
    studies = get_studies_for_project(project_id)
    
    # 2. Patient ID별로 그룹핑
    grouped_by_patient = group_by_patient_id(studies)
    
    # 3. 각 Patient ID에 대해 Subject 생성
    for patient_id, study_list in grouped_by_patient.items():
        create_subject_if_not_exists(project_id, patient_id)
```

### 2. Subject Code 생성

#### Patient ID가 있는 경우
```python
def generate_subject_code(project_id, patient_id):
    base_code = patient_id
    code = base_code
    suffix = 1
    
    while subject_code_exists(project_id, code):
        code = f"{base_code}_{suffix}"
        suffix += 1
    
    return code
```

**예시**:
- `P12345` → `P12345`
- 중복 시 → `P12345_1`, `P12345_2`, ...

#### Patient ID가 없는 경우
```python
def generate_auto_subject_code(project_id):
    for prefix in 'ABCDEFGHIJKLMNOPQRSTUVWXYZ':
        for num in range(1, 1000):
            code = f"{prefix}-{num:03d}"
            
            if not subject_code_exists(project_id, code):
                return code
    
    raise Exception("Failed to generate unique subject code")
```

**예시**:
- `A-001`, `A-002`, ..., `A-999`
- `B-001`, `B-002`, ..., `B-999`
- ...

### 3. 중복 방지

```python
# 이미 Subject가 있는 경우 건너뜀
existing_subject = find_subject_by_patient_id(project_id, patient_id)

    print(f"  ⏭️  Subject 이미 존재: {existing_subject['subject_code']}")
    continue
```

SELECT DISTINCT s.id, s.study_uid, s.patient_id, s.patient_name, s.patient_birth_date
FROM project_data pd
JOIN project_data_study s ON pd.study_id = s.id
WHERE pd.project_id = %s
  AND pd.resource_level = 'STUDY'
ORDER BY s.patient_id NULLS LAST, s.id

## 🔧 트러블슈팅

### 문제 1: DB 연결 실패
```
Error: could not connect to server
```

**해결**:
1. `.env` 파일 확인
2. DB 서버 실행 확인
3. 방화벽 설정 확인

### 문제 2: Subject Code 중복
```
Error: duplicate key value violates unique constraint
```

**해결**:
- 자동으로 접미사 추가 (_1, _2, ...)
- 코드에서 이미 처리됨

### 문제 3: Patient ID가 모두 NULL
```
⚠️  Patient ID 없음: 134개
```

**해결**:
- 정상 동작 (자동 코드 생성: A-001, A-002, ...)
- PACS Archive에서 메타데이터 조회 필요

## ✅ 검증 방법

### 1. Subject 개수 확인
```sql
SELECT
    p.id,
    p.name,
    COUNT(DISTINCT ps.id) as subject_count,
    COUNT(DISTINCT pd.study_id) as study_count
FROM security_project p
LEFT JOIN project_subject ps ON p.id = ps.project_id
LEFT JOIN project_data pd ON p.id = pd.project_id AND pd.resource_level = 'STUDY'
GROUP BY p.id, p.name
ORDER BY p.id;
```

### 2. Patient ID 매핑 확인
```sql
SELECT
    ps.subject_code,
    ps.patient_id,
    COUNT(DISTINCT s.id) as study_count
FROM project_subject ps
LEFT JOIN project_data_study s ON ps.patient_id = s.patient_id
WHERE ps.project_id = 1
GROUP BY ps.subject_code, ps.patient_id
ORDER BY ps.subject_code;
```

### 3. Patient ID 없는 Subject 확인
```sql
SELECT
    project_id,
    subject_code,
    patient_id
FROM project_subject
WHERE patient_id IS NULL
ORDER BY project_id, subject_code;
```
