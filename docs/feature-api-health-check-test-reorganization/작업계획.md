# API Health Check 테스트 재구성 작업 계획

## 📋 작업 개요

**목표**: API Health Check 대시보드의 테스트 구조를 논리적으로 재구성하여 프로젝트 생명주기 중심으로 통합

**작업 브랜치**: `feature/clarify-project-state-enum`

**작업 일자**: 2025-11-11

---

## 🎯 작업 목표

### 1. 테스트 구조 단순화
- 에러 처리 섹션을 프로젝트 생명주기 섹션으로 통합
- 모든 프로젝트 관련 테스트를 하나의 논리적 흐름으로 구성

### 2. 의존성 트리 개선
- 에러 처리 테스트도 프로젝트 생성에 의존하도록 구성
- 테스트 실행 순서를 명확하게 정의

### 3. 코드 정리
- 불필요한 `runErrorTest` 함수 제거
- 섹션 인덱스 처리 로직 단순화

## 📝 작업 단계

### Phase 1: 잘못된 상태 값 처리 이동
**목표**: "잘못된 상태 값 처리" 테스트를 프로젝트 생명주기로 이동

**작업 내용**:
1. ✅ 프로젝트 생명주기 섹션에 "잘못된 상태 값 처리" 추가 (testIndex 6)
2. ✅ "테스트 프로젝트 삭제"를 testIndex 7로 변경
3. ✅ `runLifecycleTest` 함수에 testIndex 6 처리 로직 추가
4. ✅ 의존성 업데이트: "잘못된 상태 값 처리" → "IN_PROGRESS → COMPLETED"
5. ✅ 의존성 업데이트: "테스트 프로젝트 삭제" → "잘못된 상태 값 처리"

**예상 결과**:
- 잘못된 상태 값 처리가 프로젝트 생명주기 내에서 실행됨
- 상태 변경 후 에러 처리가 자연스럽게 이어짐

### Phase 2: 존재하지 않는 프로젝트 조회 이동
**목표**: "존재하지 않는 프로젝트 조회" 테스트를 프로젝트 생명주기로 이동

**작업 내용**:
1. ✅ 프로젝트 생명주기 섹션에 "존재하지 않는 프로젝트 조회" 추가 (testIndex 7)
2. ✅ "테스트 프로젝트 삭제"를 testIndex 8로 변경
3. ✅ `runLifecycleTest` 함수에 testIndex 7 처리 로직 추가
4. ✅ 의존성 업데이트: "존재하지 않는 프로젝트 조회" → "잘못된 상태 값 처리"
5. ✅ 의존성 업데이트: "테스트 프로젝트 삭제" → "존재하지 않는 프로젝트 조회"

**예상 결과**:
- 모든 에러 처리 테스트가 프로젝트 생명주기 내에서 실행됨
- 에러 처리 섹션이 비어있게 됨

### Phase 3: 에러 처리 섹션 제거
**목표**: 빈 에러 처리 섹션 제거 및 코드 정리

**작업 내용**:
1. ✅ `sections` state에서 에러 처리 섹션 제거
2. ✅ `runTest` 함수에서 sectionIndex 2 처리 제거
3. ✅ `runErrorTest` 함수 제거
4. ✅ 컴파일 에러 확인 및 수정

**예상 결과**:
- 섹션이 2개로 단순화됨 (메타데이터, 프로젝트 생명주기)
- 코드가 더 간결해짐

## 🔍 테스트 계획

### 테스트 시나리오

#### 시나리오 1: 전체 테스트 실행
1. 브라우저에서 http://localhost:3002 접속
2. API 점검 탭 클릭
3. "▶️ 모든 테스트 실행" 클릭
4. 모든 테스트가 순서대로 성공하는지 확인

**예상 결과**:
```
✅ 프로젝트 생성 (PREPARING)
  ✅ 프로젝트 조회
  ✅ PREPARING → IN_PROGRESS
    ✅ IN_PROGRESS → ON_HOLD
      ✅ ON_HOLD → IN_PROGRESS
        ✅ IN_PROGRESS → COMPLETED
  ✅ 잘못된 상태 값 처리
  ✅ 존재하지 않는 프로젝트 조회
  ✅ 테스트 프로젝트 삭제
```

#### 시나리오 2: 개별 테스트 실행
1. "잘못된 상태 값 처리" 테스트만 실행
2. 의존성 테스트들이 자동으로 실행되는지 확인

**예상 결과**:
- 프로젝트 생성 → 상태 변경 → 잘못된 상태 값 처리 순서로 실행됨

#### 시나리오 3: UI 확인
1. 테스트 목록에서 들여쓰기 확인
2. 의존성 배지 확인
3. 순차 실행 배지 확인
4. 정리 배지 확인

**예상 결과**:
- 모든 테스트가 적절히 들여쓰기됨
- 배지가 올바르게 표시됨
