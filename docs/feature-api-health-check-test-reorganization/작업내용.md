## 🎯 작업 배경

### 문제 상황
사용자가 API Health Check 대시보드의 테스트 구조를 검토한 결과, 에러 처리 테스트들이 별도 섹션으로 분리되어 있어 논리적 흐름이 명확하지 않았습니다.

**기존 구조**:
```
📊 프로젝트 메타데이터 (3개 테스트)
🔄 프로젝트 생명주기 (6개 테스트)
  - 프로젝트 생성
  - 프로젝트 조회
  - 상태 변경 (4단계)
  - 테스트 프로젝트 삭제

⚠️ 에러 처리 (2개 테스트)
  - 잘못된 상태 값 처리 (프로젝트 생성 필요)
  - 존재하지 않는 프로젝트 조회
```

**문제점**:
1. "잘못된 상태 값 처리"는 프로젝트가 필요하지만 별도 섹션에 있음
2. 에러 처리 테스트가 프로젝트 생명주기와 분리되어 있어 의존성이 불명확함
3. 테스트 실행 순서가 직관적이지 않음

### 사용자 요구사항
1. "잘못된 상태 값 처리"를 프로젝트 생명주기 하위로 이동
2. "존재하지 않는 프로젝트 조회"도 프로젝트 생명주기 하위로 이동
3. 모든 프로젝트 관련 테스트를 하나의 논리적 흐름으로 통합

```typescript
} else if (testIndex === 7) {
  // 존재하지 않는 프로젝트 조회
  const requestInfo = { method: 'GET', url: '/api/projects/999999' };

  try {
    await axios.get(`${apiUrl}/api/projects/999999`);
    throw new Error('404 에러가 발생해야 하는데 성공했습니다');
  } catch (error: any) {
    if (error.response?.status === 404) {
      return {
        request: requestInfo,
        response: error.response.data || { status: 404, message: 'Not Found' },
      };
    }

    // 404가 아닌 다른 에러 - 에러에 요청 정보 포함
    if (!error.config) {
      error.config = {
        method: 'get',
        url: `${apiUrl}/api/projects/999999`,
      };
    }
    throw error;
  }
}
```

**삭제 테스트 인덱스 변경**:
```typescript
} else if (testIndex === 8) {  // 이전: testIndex === 7
  // 테스트 프로젝트 삭제 (cleanup)
  const projectId = createdProjectIdRef.current;
  
  if (!projectId) {
    throw new Error('삭제할 프로젝트가 없습니다.');
  }

  const deletedId = projectId;
  
  try {
    const response = await axios.delete(`${apiUrl}/api/projects/${projectId}`);

    // 삭제 후 ID 초기화 (state + ref)
    setCreatedProjectId(null);
    createdProjectIdRef.current = null;

    return {
      request: { method: 'DELETE', url: `/api/projects/${deletedId}` },
      response: response.data || { message: '프로젝트가 삭제되었습니다' },
    };
  } catch (error: any) {
    // 삭제 실패해도 ID 초기화 (다음 테스트를 위해)
    setCreatedProjectId(null);
    createdProjectIdRef.current = null;
    
    // 에러에 요청 정보 포함
    if (!error.config) {
      error.config = {
        method: 'delete',
        url: `${apiUrl}/api/projects/${deletedId}`,
      };
    }
    throw error;
  }
}
```
