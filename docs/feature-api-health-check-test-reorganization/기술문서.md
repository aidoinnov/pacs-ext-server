## 🔧 핵심 기술

### 1. 테스트 의존성 관리

#### 의존성 정의
```typescript
interface Test {
  name: string;
  status: 'pending' | 'running' | 'success' | 'failure' | 'skipped';
  dependencies?: string[];  // 의존하는 테스트 이름 목록
  indentLevel?: number;     // UI 들여쓰기 레벨
  isSequential?: boolean;   // 순차 실행 여부
  cleanup?: boolean;        // 정리 작업 여부
  delayAfter?: number;      // 실행 후 대기 시간 (ms)
}
```

#### 의존성 해결 알고리즘
```typescript
const canRunTest = (test: Test): boolean => {
  if (!test.dependencies || test.dependencies.length === 0) {
    return true;  // 의존성 없음 - 실행 가능
  }

  // 모든 의존 테스트가 성공했는지 확인
  return test.dependencies.every(depName => {
    const depTest = findTestByName(depName);
    return depTest && depTest.status === 'success';
  });
};
```

### 2. 동기적 상태 관리 (useRef)

#### 문제: useState의 비동기성
```typescript
// ❌ 문제 상황
const [createdProjectId, setCreatedProjectId] = useState<number | null>(null);

// 프로젝트 생성
setCreatedProjectId(response.data.id);

// 즉시 다음 테스트 실행
if (!createdProjectId) {  // ⚠️ 아직 null! (setState는 비동기)
  throw new Error('프로젝트가 생성되지 않았습니다');
}
```

#### 해결: useRef 사용
```typescript
// ✅ 해결 방법
const createdProjectIdRef = useRef<number | null>(null);

// 프로젝트 생성
const projectId = response.data.id;
setCreatedProjectId(projectId);           // UI 업데이트용
createdProjectIdRef.current = projectId;  // 즉시 업데이트됨

// 즉시 다음 테스트 실행
const projectId = createdProjectIdRef.current;  // ✅ 올바른 값!
if (!projectId) {
  throw new Error('프로젝트가 생성되지 않았습니다');
}
```

#### 동작 원리
```
useState (비동기):
  setCreatedProjectId(123)
    ↓ (비동기 - 다음 렌더링 사이클에 반영)
  createdProjectId === null (아직 업데이트 안됨)
    ↓ (렌더링 후)
  createdProjectId === 123

useRef (동기):
  createdProjectIdRef.current = 123
    ↓ (동기적 - 즉시 반영)
  createdProjectIdRef.current === 123 (바로 사용 가능!)
```

### 3. 테스트 실행 흐름

#### runLifecycleTest 함수 구조
```typescript
const runLifecycleTest = async (testIndex: number) => {
  const apiUrl = APP_CONSTANTS.API_URL;

  if (testIndex === 0) {
    // 프로젝트 생성
    const projectData = { /* ... */ };
    const response = await axios.post(`${apiUrl}/api/projects`, projectData);
    
    // State + Ref 모두 업데이트
    const projectId = response.data.id;
    setCreatedProjectId(projectId);
    createdProjectIdRef.current = projectId;
    
    return { request, response: response.data };
    
  } else if (testIndex === 1) {
    // 프로젝트 조회 (재시도 로직 포함)
    const projectId = createdProjectIdRef.current;  // Ref 사용!
    
    if (!projectId) {
      throw new Error('프로젝트가 생성되지 않았습니다');
    }
    
    // 최대 3번 재시도
    for (let attempt = 1; attempt <= 3; attempt++) {
      try {
        const response = await axios.get(`${apiUrl}/api/projects/${projectId}`);
        return { request, response: response.data };
      } catch (error) {
        if (attempt < 3) {
          await new Promise(resolve => setTimeout(resolve, 500));
        }
      }
    }
    
  } else if (testIndex === 2) {
    // PREPARING → IN_PROGRESS
    // ...
    
  } else if (testIndex === 6) {
    // 잘못된 상태 값 처리 (에러 케이스)
    const projectId = createdProjectIdRef.current;
    const updateData = { status: 'INVALID_STATUS', end_date: '' };
    
    const response = await axios.put(`${apiUrl}/api/projects/${projectId}`, updateData);
    // 잘못된 상태는 무시되고 200 응답이 와야 함
    
    return { request, response: response.data };
    
  } else if (testIndex === 7) {
    // 존재하지 않는 프로젝트 조회 (에러 케이스)
    try {
      await axios.get(`${apiUrl}/api/projects/999999`);
      throw new Error('404 에러가 발생해야 하는데 성공했습니다');
    } catch (error: any) {
      if (error.response?.status === 404) {
        return { request, response: error.response.data };
      }
      throw error;
    }
    
  } else if (testIndex === 8) {
    // 테스트 프로젝트 삭제 (정리)
    const projectId = createdProjectIdRef.current;
    const response = await axios.delete(`${apiUrl}/api/projects/${projectId}`);
    
    // 삭제 후 ID 초기화
    setCreatedProjectId(null);
    createdProjectIdRef.current = null;
    
    return { request, response: response.data };
  }
};
```

### 4. 에러 처리

#### 요청 정보 포함
모든 테스트에서 에러 발생 시 요청 정보를 포함하여 디버깅을 용이하게 합니다:

```typescript
try {
  const response = await axios.put(`${apiUrl}/api/projects/${projectId}`, updateData);
  return { request, response: response.data };
} catch (error: any) {
  // 에러에 요청 정보 포함
  if (!error.config) {
    error.config = {
      method: 'put',
      url: `${apiUrl}/api/projects/${projectId}`,
      data: updateData,
    };
  }
  throw error;
}
```

#### runTest 함수의 에러 처리
```typescript
const runTest = async (sectionIndex: number, testIndex: number) => {
  // ...
  
  try {
    let result;
    
    if (sectionIndex === 0) {
      result = await runMetadataTest(testIndex);
    } else if (sectionIndex === 1) {
      result = await runLifecycleTest(testIndex);
    }
    
    test.status = 'success';
    test.request = result?.request;
    test.response = result?.response;
    test.duration = Date.now() - startTime;
    
  } catch (error: any) {
    test.status = 'failure';
    test.error = error.message || 'Unknown error';
    
    // 요청 정보 추출
    if (error.config) {
      const method = error.config.method?.toUpperCase() || 'UNKNOWN';
      const url = error.config.url || 'unknown';
      let body = undefined;
      
      if (error.config.data) {
        try {
          body = typeof error.config.data === 'string' 
            ? JSON.parse(error.config.data) 
            : error.config.data;
        } catch {
          body = error.config.data;
        }
      }
      
      test.request = { method, url, ...(body && { body }) };
    }
    
    // 응답 정보 추출
    if (error.response) {
      test.response = error.response.data;
    }
    
    test.duration = Date.now() - startTime;
  }
};
```

## 📊 데이터 흐름

### 테스트 실행 시퀀스

```
사용자 클릭 "모든 테스트 실행"
  ↓
runAllTests()
  ├─ 모든 테스트를 pending으로 초기화
  ├─ createdProjectId 초기화 (state + ref)
  └─ 섹션별로 순회
      ↓
각 섹션 처리
  ├─ isSequential === true → 순차 실행
  │   └─ 테스트를 하나씩 실행
  │       ├─ 의존성 확인 (canRunTest)
  │       ├─ runTest(sectionIndex, testIndex)
  │       └─ delayAfter 대기
  │
  └─ isSequential === false → 병렬 실행
      └─ Promise.all로 모든 테스트 동시 실행
          ├─ 의존성 확인 (canRunTest)
          └─ runTest(sectionIndex, testIndex)
```

### 상태 업데이트 흐름

```
runTest 시작
  ↓
test.status = 'running'
setSections([...]) → UI 업데이트
  ↓
runLifecycleTest(testIndex) 실행
  ↓
testIndex === 0 (프로젝트 생성)
  ├─ API 호출: POST /api/projects
  ├─ setCreatedProjectId(id) → UI용
  ├─ createdProjectIdRef.current = id → 동기 접근용
  └─ return { request, response }
  ↓
test.status = 'success'
test.request = result.request
test.response = result.response
setSections([...]) → UI 업데이트
  ↓
delayAfter 대기 (1500ms)
  ↓
다음 테스트 실행
```

### 일반적인 문제 해결

#### 문제 1: 프로젝트 조회 실패
```
증상: "프로젝트가 생성되지 않았습니다" 에러
원인: createdProjectIdRef.current가 null
해결: 
  1. 프로젝트 생성 테스트가 성공했는지 확인
  2. createdProjectIdRef.current 업데이트 확인
  3. 콘솔 로그에서 "💾 createdProjectId 저장 완료" 메시지 확인
```

#### 문제 2: 의존성 테스트 스킵됨
```
증상: 테스트가 "⏭️ 스킵됨" 상태
원인: 의존하는 테스트가 실패했거나 아직 실행되지 않음
해결:
  1. 의존성 배지에서 어떤 테스트에 의존하는지 확인
  2. 해당 테스트의 상태 확인
  3. 의존 테스트를 먼저 실행
```

#### 문제 3: 404 에러 (존재하지 않는 프로젝트)
```
증상: "존재하지 않는 프로젝트 조회" 테스트가 실패
원인: 백엔드가 404를 반환하지 않음
해결:
  1. 백엔드 서버가 실행 중인지 확인
  2. /api/projects/999999 엔드포인트 확인
  3. 응답 정보에서 실제 상태 코드 확인
```
