# Role Capability Matrix API - Scope 필터링 개선 작업 계획

## 📋 작업 개요

**목표**: `/api/roles/global/capabilities/matrix/all` 엔드포인트를 진짜 "전역(global)" 엔드포인트로 변경하고, `scope` 쿼리 파라미터로 필터링하도록 개선

**브랜치**: `feature/dicom-global-access`

**작업 일자**: 2025-11-12

---

## 🎯 변경 후 동작

```bash
# 모든 역할 조회 (GLOBAL + PROJECT)
GET /api/roles/global/capabilities/matrix/all

# GLOBAL scope 역할만 조회
GET /api/roles/global/capabilities/matrix/all?scope=GLOBAL

# PROJECT scope 역할만 조회
GET /api/roles/global/capabilities/matrix/all?scope=PROJECT
```

## 🔍 기술적 고려사항

### 기존 문제점

1. **페이지네이션 버전** (`/api/roles/global/capabilities/matrix`)
   - 기본적으로 `scope = 'GLOBAL'` 조건이 하드코딩되어 있음
   - scope 파라미터를 받긴 하는데, **AND 조건으로 추가**되어서 충돌 발생

2. **전체 데이터 버전** (`/api/roles/global/capabilities/matrix/all`)
   - scope 파라미터를 받지 않음
   - `WHERE scope = 'GLOBAL'` 하드코딩

### 해결 방안

- 하드코딩된 `scope = 'GLOBAL'` 조건 제거
- 동적 WHERE 절 생성:
  - scope 파라미터가 있으면: `WHERE scope = $1`
  - scope 파라미터가 없으면: WHERE 절 없음 (모든 역할 반환)
