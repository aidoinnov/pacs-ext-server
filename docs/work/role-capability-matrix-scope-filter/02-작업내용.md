### 1. Repository 계층 수정 ✅

**파일**: `pacs-server/src/infrastructure/repositories/capability_repository_impl.rs`

#### 변경 사항:

1. **`get_global_role_capability_matrix()` 메서드**
   - `scope: Option<&str>` 파라미터 추가
   - 동적 WHERE 절 생성 로직 구현:
     ```rust
     let where_clause = if let Some(scope_filter) = scope {
         if !scope_filter.trim().is_empty() {
             format!("WHERE scope = '{}'", scope_filter)
         } else {
             String::new()
         }
     } else {
         String::new()
     };
     ```

2. **`get_global_role_capability_matrix_paginated()` 메서드**
   - 하드코딩된 `scope = 'GLOBAL'` 조건 제거
   - 기존 코드:
     ```rust
     let mut where_conditions = vec!["scope = 'GLOBAL'".to_string()];
     ```
   - 변경 후:
     ```rust
     let mut where_conditions = Vec::new();
     ```

## 🔧 기술적 세부사항

### 동적 SQL 쿼리 생성

**Before**:
```sql
SELECT id, name, description, scope, created_at
FROM security_role
WHERE scope = 'GLOBAL'  -- 하드코딩
ORDER BY name
```

**After**:
```sql
-- scope 파라미터가 있을 때
SELECT id, name, description, scope, created_at
FROM security_role
WHERE scope = 'GLOBAL'  -- 동적으로 생성
ORDER BY name

-- scope 파라미터가 없을 때
SELECT id, name, description, scope, created_at
FROM security_role
ORDER BY name
```
