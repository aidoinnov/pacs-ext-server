## 🛠️ 기술 스택

### 백엔드
- **언어**: Rust
- **프레임워크**: Actix-web
- **HTTP 클라이언트**: reqwest
- **직렬화**: serde, serde_json

### 인증
- **인증 서버**: Keycloak
- **프로토콜**: OpenID Connect
- **Grant Types**: 
  - Client Credentials (관리 작업)
  - Password Grant (사용자 인증)
  - Refresh Token (토큰 갱신)

### 테스트
- **단위 테스트**: tokio::test, mockito
- **통합 테스트**: actix-web test utilities
- **성능 테스트**: criterion (향후)
