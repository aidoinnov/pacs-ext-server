## 🔍 문제 상황

### 1. S3 Presigned URL 업로드 403 에러

#### 에러 메시지
```xml
<?xml version="1.0" encoding="UTF-8"?>
<Error>
  <Code>AccessDenied</Code>
  <Message>There were headers present in the request which were not signed</Message>
  <HeadersNotSigned>
    x-amz-meta-annotation_id,
    x-amz-meta-mask_group_id,
    x-amz-meta-file_type,
    x-amz-acl,
    x-amz-meta-user_id,
    x-amz-storage-class
  </HeadersNotSigned>
  <RequestId>F2TRHMSC93S7JEQR</RequestId>
  <HostId>4PLzwFf8NzciPMdndv1tXM/vUuzlCLgzNh41aFQ0Fa5Im5YCy3SlaDFmYxLwFIEURBmB8m17X4I=</HostId>
</Error>
```

#### 원인 분석
- **클라이언트**가 다음 헤더들을 전송:
  - `x-amz-acl: private`
  - `x-amz-storage-class: STANDARD`
  - `x-amz-meta-annotation_id`
  - `x-amz-meta-mask_group_id`
  - `x-amz-meta-file_type`
  - `x-amz-meta-user_id`

- **서버**가 생성한 presigned URL에는 이 헤더들이 서명에 포함되지 않음
- AWS S3는 **서명되지 않은 헤더**가 요청에 포함되면 403 에러 반환

### 2. Mask API 404 에러

#### 에러 상황
```
Request URL: http://localhost:8080/api/annotations/239/mask-groups/103/masks
Request Method: POST
Status Code: 404 Not Found
```

#### 원인 분석
- Mask 라우트가 `mask_controller.rs`에 별도로 정의됨
- `main.rs`에서 `mask_controller`를 별도로 등록했으나 스코프 설정 오류
- `/api/annotations` 스코프 계층에 포함되지 않음

### 1. S3 Presigned URL 생성 로직 수정

#### 파일: `pacs-server/src/infrastructure/external/s3_service.rs`

**수정 전 (라인 100-126)**:
```rust
async fn generate_upload_url(
    &self,
    file_path: &str,
    options: SignedUrlOptions,
) -> Result<String, ObjectStorageError> {
    let key = self.file_path_to_key(file_path);

    let presigning_config = PresigningConfig::expires_in(Duration::from_secs(options.ttl_seconds))
        .map_err(|e| ObjectStorageError::S3Error(format!("Failed to create presigning config: {}", e)))?;

    let mut put_object = self.client
        .put_object()
        .bucket(&self.bucket_name)
        .key(&key);

    // ❌ 문제: 메타데이터, ACL, Storage Class 추가
    if let Some(content_type) = options.content_type {
        put_object = put_object.content_type(content_type);
    }
    
    // 메타데이터 추가 (서명에 포함되지 않음)
    if let Some(metadata) = options.metadata {
        for (key, value) in metadata {
            put_object = put_object.metadata(key, value);
        }
    }
    
    // ACL 설정 (서명에 포함되지 않음)
    put_object = put_object.set_acl(Some(ObjectCannedAcl::Private));
    
    // Storage Class 설정 (서명에 포함되지 않음)
    put_object = put_object.set_storage_class(Some(StorageClass::Standard));

    let request = put_object
        .presigned(presigning_config)
        .await
        .map_err(|e| self.map_s3_error(e.into()))?;

    Ok(request.uri().to_string())
}
```

**수정 후 (라인 100-126)**:

- ❌ 제거: Storage Class 설정 (`set_storage_class`)
- ✅ 유지: Content-Type만 설정

#### 파일: `pacs-server/src/infrastructure/external/minio_service.rs`

```rust
async fn generate_upload_url(
    &self,
    file_path: &str,
    options: SignedUrlOptions,
) -> Result<String, ObjectStorageError> {
    let key = self.file_path_to_key(file_path);
    
    let presigning_config = PresigningConfig::expires_in(Duration::from_secs(options.ttl_seconds))
        .map_err(|e| ObjectStorageError::MinIOError(format!("Failed to create presigning config: {}", e)))?;
    
    let mut put_object = self.client
        .put_object()
        .bucket(&self.bucket_name)
        .key(&key);
    
    // ✅ Content-Type만 설정 (클라이언트는 Content-Type만 보내야 함)
    if let Some(content_type) = options.content_type {
        put_object = put_object.content_type(content_type);
    }
    
    let request = put_object
        .presigned(presigning_config)
        .await
        .map_err(|e| self.map_minio_error(e.into()))?;
    
    Ok(request.uri().to_string())
}
```

- ❌ 제거: `x-amz-acl` 헤더 전송
- ❌ 제거: `x-amz-storage-class` 헤더 전송
- ❌ 제거: `x-amz-meta-*` 메타데이터 헤더 전송
