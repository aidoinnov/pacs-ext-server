## 🔧 수정된 버그

### 버그 1: 역할 할당 API 실패 ✅
**API**: `PUT /api/projects/{project_id}/users/{user_id}/role`

**문제**:
- 사용자가 프로젝트에 참여중이지만 `role_id = NULL` (Unassigned 상태)인 경우 역할 할당 실패
- 기존 로직이 멤버십 존재 여부만 확인하고 INSERT 시도 → 중복 에러 발생

**해결**:
- `ProjectServiceImpl::assign_user_role_in_project()` 함수 재작성
- 멤버십 존재 시 UPDATE, 없으면 INSERT 로직으로 변경

### 버그 2: 멤버 추가 API 실패 ✅
**API**: `POST /api/projects/{project_id}/members`

**문제**:
- 사용자가 프로젝트에 참여중이지만 `role_id = NULL`인 경우 멤버 추가 실패
- 에러: `409 Conflict - "User is already a member of this project"`

**해결**:
- `UserServiceImpl::add_user_to_project_with_role()` 함수 재작성
- 멤버십 존재 시 UPDATE, 없으면 INSERT 로직으로 변경

async fn assign_user_role_in_project(
    &self,
    user_id: i32,
    project_id: i32,
    role_id: i32,
) -> Result<(), ServiceError> {
    let pool = self.project_repository.pool();
    let mut tx = pool.begin().await?;

    // 1. 사용자 존재 확인
    // 2. 프로젝트 존재 확인
    // 3. 역할 존재 확인
    
    // 4. 멤버십 존재 여부 확인
    let is_member: bool = sqlx::query_scalar(
        "SELECT EXISTS(SELECT 1 FROM security_user_project WHERE user_id = $1 AND project_id = $2)"
    )
    .bind(user_id)
    .bind(project_id)
    .fetch_one(&mut *tx)
    .await?;

    if is_member {
        // 4-1. 이미 멤버: role_id UPDATE
        sqlx::query(
            "UPDATE security_user_project SET role_id = $1 WHERE user_id = $2 AND project_id = $3"
        )
        .bind(role_id)
        .bind(user_id)
        .bind(project_id)
        .execute(&mut *tx)
        .await?;
    } else {
        // 4-2. 멤버 아님: 새로운 레코드 INSERT
        sqlx::query(
            "INSERT INTO security_user_project (user_id, project_id, role_id, created_at) 
             VALUES ($1, $2, $3, NOW())"
        )
        .bind(user_id)
        .bind(project_id)
        .bind(role_id)
        .execute(&mut *tx)
        .await?;
    }

    tx.commit().await?;
    Ok(())
}

**변경 후**:
```rust
async fn add_user_to_project_with_role(
    &self,
    user_id: i32,
    project_id: i32,
    role_id: Option<i32>,
) -> Result<(), ServiceError> {
    let pool = self.user_repository.pool();
    let mut tx = pool.begin().await?;

    // 1. 사용자 존재 확인
    // 2. 프로젝트 존재 확인
    
    // 3. 기본 역할 설정 (role_id가 None이면 Viewer 역할 사용)
    let final_role_id = match role_id {
        Some(id) => id,
        None => {
            // Viewer 역할 조회
            sqlx::query_scalar("SELECT id FROM security_role WHERE name = 'Viewer' LIMIT 1")
                .fetch_one(&mut *tx)
                .await?
        }
    };

    // 4. 멤버십 존재 여부 확인
    let is_member: bool = sqlx::query_scalar(
        "SELECT EXISTS(SELECT 1 FROM security_user_project WHERE user_id = $1 AND project_id = $2)"
    )
    .bind(user_id)
    .bind(project_id)
    .fetch_one(&mut *tx)
    .await?;

    if is_member {
        // 4-1. 이미 멤버: role_id UPDATE
        tracing::info!("User {} is already a member of project {}. Updating role to {}", 
            user_id, project_id, final_role_id);
        
        sqlx::query(
            "UPDATE security_user_project SET role_id = $1 WHERE user_id = $2 AND project_id = $3"
        )
        .bind(final_role_id)
        .bind(user_id)
        .bind(project_id)
        .execute(&mut *tx)
        .await?;
    } else {
        // 4-2. 멤버 아님: 새로운 레코드 INSERT
        tracing::info!("User {} is not a member of project {}. Adding as new member with role {}", 
            user_id, project_id, final_role_id);
        
        sqlx::query(
            "INSERT INTO security_user_project (user_id, project_id, role_id, created_at) 
             VALUES ($1, $2, $3, NOW())"
        )
        .bind(user_id)
        .bind(project_id)
        .bind(final_role_id)
        .execute(&mut *tx)
        .await?;
    }

    tx.commit().await?;
    Ok(())
}
```

**주요 변경사항**:
- ✅ 트랜잭션 관리 추가
- ✅ 기본 역할 설정 로직 추가 (Viewer)
- ✅ 멤버십 존재 여부 확인 로직 추가
- ✅ UPDATE/INSERT 분기 처리
- ✅ `tracing::info!` 로그 추가
- ✅ `updated_at` 컬럼 제거
