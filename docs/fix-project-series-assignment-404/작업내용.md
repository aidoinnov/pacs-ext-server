### 4. Use Case 메서드 추가

**파일**: `pacs-server/src/application/use_cases/project_data_access_use_case.rs`

#### 4.1 `assign_series_to_project` 메서드

**로직**:
1. 프로젝트 존재 확인
2. Study 조회 또는 생성 (`project_data_study` 테이블)
   - Study가 없으면 `INSERT ... ON CONFLICT` 사용하여 생성
   - `project_data` 테이블에 Study 매핑 추가 (resource_level='STUDY')
3. Series 조회 또는 생성 (`project_data_series` 테이블)
   - `INSERT ... ON CONFLICT` 사용하여 중복 방지
4. `project_data` 테이블에 Series 매핑 추가 (resource_level='SERIES')
5. 성공 응답 반환

**핵심 SQL**:
```sql
-- Study 생성 (중복 시 업데이트)
INSERT INTO project_data_study (study_uid, study_description)
VALUES ($1, $2)
ON CONFLICT (study_uid) DO UPDATE SET study_uid = EXCLUDED.study_uid
RETURNING id, study_uid, ...

-- Study 매핑 추가
INSERT INTO project_data (project_id, resource_level, study_id)
VALUES ($1, 'STUDY'::resource_level_enum, $2)
ON CONFLICT DO NOTHING

-- Series 생성 (중복 시 업데이트)
INSERT INTO project_data_series (study_id, series_uid, series_description, modality, series_number)
VALUES ($1, $2, $3, $4, $5)
ON CONFLICT (study_id, series_uid) DO UPDATE 
SET series_description = EXCLUDED.series_description, ...
RETURNING id, study_id, series_uid, ...

-- Series 매핑 추가
INSERT INTO project_data (project_id, resource_level, study_id, series_id)
VALUES ($1, 'SERIES'::resource_level_enum, $2, $3)
ON CONFLICT DO NOTHING
RETURNING id
```

**에러 처리**:
- 404: 프로젝트를 찾을 수 없음
- 409: Series가 이미 프로젝트에 할당됨 (중복)
- 500: 데이터베이스 오류

## ⚠️ 주의사항

1. **트랜잭션 미사용**
   - 현재 구현은 트랜잭션을 사용하지 않음
   - 향후 개선 시 트랜잭션 추가 권장

2. **Study 자동 생성**
   - Series 할당 시 부모 Study가 없으면 자동 생성됨
   - Study 정보가 최소한으로만 저장됨 (study_uid, study_description)

3. **중복 할당 처리**
   - `ON CONFLICT DO NOTHING` 사용
   - 중복 시 `RETURNING id`가 NULL이므로 409 Conflict 반환

4. **데이터 정합성**
   - Study는 전역 엔티티 (study_uid UNIQUE)
   - Series는 Study에 종속 (study_id FK)
   - 프로젝트 매핑은 project_data 테이블에서 관리
