## 🎯 작업 목적

### 1. 문제 상황
- **현재 상태**: `POST /api/projects/107/series/assign` 요청 시 **404 오류** 발생

- ✅ 프로젝트 데이터 목록 조회 시 프로젝트에 포함된 데이터만 출력
- ✅ 테스트 코드 추가로 기능 검증

## 🔍 현재 상태 분석

### 1. 라우트 구조 분석

#### 현재 등록된 라우트 (`project_data_access_controller.rs`)
```rust
web::scope("/project-data")
    .route("/{project_id}/data-access/matrix", web::get().to(...))
    .route("/{project_id}/data", web::post().to(create_project_data))
    .route("/{project_id}/studies", web::get().to(get_project_studies))
    .route("/{project_id}/studies/{study_id}/series", web::get().to(get_study_series))
    .route("/{project_id}/series/{series_id}/instances", web::get().to(get_series_instances))
```

**실제 URL**: `/api/project-data/{project_id}/...`

#### 사용자가 요청한 URL
```
POST /api/projects/107/series/assign
```

**문제**: 
- 요청 URL은 `/api/projects/...`를 사용
- 실제 등록된 라우트는 `/api/project-data/...`를 사용
- **Series 할당 엔드포인트가 아예 존재하지 않음**

### 2. 문서 분석 (`docs/api/project-study-series-assignment-api.md`)

| API | 상태 | 엔드포인트 |
|-----|------|-----------|
| Study 목록 조회 | ✅ 구현 완료 | `GET /api/project-data/{project_id}/studies` |
| Series 목록 조회 | ✅ 구현 완료 | `GET /api/project-data/{project_id}/studies/{study_id}/series` |
| **Study 할당** | ⏳ **미구현** | `POST /api/projects/{project_id}/studies/assign` |
| **Series 할당** | ⏳ **미구현** | `POST /api/projects/{project_id}/series/assign` |
| Study 할당 해제 | ⏳ 미구현 | `DELETE /api/projects/{project_id}/studies/{study_uid}` |
| Series 할당 해제 | ⏳ 미구현 | `DELETE /api/projects/{project_id}/series/{series_uid}` |

**결론**: 조회 API만 구현되어 있고, **할당/해제 API는 미구현 상태**

### 3. 기존 코드 분석

#### `create_project_data` 함수 (유사 기능)
- **경로**: `POST /api/project-data/{project_id}/data`
- **기능**: Study를 프로젝트에 할당하는 기능 (이미 구현됨)
- **활용 가능성**: 이 로직을 참고하여 Series 할당 API 구현 가능

## ⚠️ 주의사항

### 1. 라우트 순서
- `/projects/{project_id}/series/assign` (구체적 경로)를 먼저 등록
- `/projects/{project_id}` (동적 경로)는 나중에 등록
- 기존 `project_controller`와 충돌하지 않도록 별도 scope 사용

### 2. 데이터 무결성
- Study가 없는 Series는 할당 불가 (부모 Study 먼저 확인)
- 중복 할당 방지 (`ON CONFLICT DO NOTHING`)
- 트랜잭션 사용으로 원자성 보장

### 3. 에러 처리
- 404: 프로젝트 또는 부모 Study를 찾을 수 없음
- 409: 이미 할당된 Series
- 400: 잘못된 요청 (필수 필드 누락)
