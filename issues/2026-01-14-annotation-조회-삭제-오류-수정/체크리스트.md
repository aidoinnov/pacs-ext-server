## 🚨 자주 놓치는 항목

### 1. RETURNING 절
```rust
// ❌ 잘못된 예
"UPDATE annotation_annotation SET data = $1
 WHERE id = $2
 RETURNING id, project_id, user_id, data"  // snapshot 필드 누락!

// ✅ 올바른 예
"UPDATE annotation_annotation SET data = $1
 WHERE id = $2
 RETURNING id, project_id, user_id, data,
           snapshot_image_key, snapshot_status, snapshot_uploaded_at,
           created_at, updated_at, version"
```

### 2. History 저장 쿼리
```rust
// delete() 메서드에서 기존 데이터 조회
let old_annotation = sqlx::query_as::<_, Annotation>(
    "SELECT * FROM annotation_annotation WHERE id = $1"  // ✅ 모든 필드 포함 확인
)
```

### 3. 페이지네이션 쿼리
```rust
// 페이지네이션 쿼리도 잊지 말고 업데이트!
async fn find_by_project_and_series_paginated(...)
```

## 🎯 핵심 원칙

1. **Entity 필드 = DB 컬럼 = SELECT 쿼리 필드**
2. **모든 SELECT 쿼리를 빠짐없이 업데이트**
3. **RETURNING 절도 잊지 말고 업데이트**
4. **테스트로 검증**
5. **문서화로 기록**
