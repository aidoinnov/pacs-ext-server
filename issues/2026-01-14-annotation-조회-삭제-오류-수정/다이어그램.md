```mermaid
sequenceDiagram

    sqlx->>DB: SELECT ... FROM annotation_annotation
    DB-->>sqlx: 17개 컬럼 반환
    
    Note over sqlx,Entity: FromRow trait 사용하여 매핑 시도
    
    sqlx->>Entity: id = row.get("id")
    Entity-->>sqlx: ✅ OK
    
    sqlx->>Entity: project_id = row.get("project_id")
    Entity-->>sqlx: ✅ OK
    
    sqlx->>Entity: snapshot_image_key = row.get("snapshot_image_key")
    Entity-->>sqlx: ❌ MissingColumn Error
    
    sqlx-->>App: Err(MissingColumn("snapshot_image_key"))
    App-->>App: HTTP 500 Internal Server Error
```

## 🎯 Entity 변경 시 체크 플로우

```mermaid
flowchart TD
    Start([Entity 필드 추가]) --> Migration{DB Migration<br/>작성 완료?}
    Migration -->|No| WriteMigration[Migration SQL 작성]
    WriteMigration --> Migration
    Migration -->|Yes| EntityUpdate[Entity 구조체 업데이트]
    
    EntityUpdate --> RepoCheck{Repository<br/>쿼리 확인}
    
    RepoCheck --> Select[모든 SELECT 쿼리<br/>업데이트]
    RepoCheck --> Insert[INSERT RETURNING<br/>업데이트]
    RepoCheck --> Update[UPDATE RETURNING<br/>업데이트]
    RepoCheck --> Delete[DELETE 전 조회<br/>업데이트]
    
    Select --> Test{테스트<br/>통과?}
    Insert --> Test
    Update --> Test
    Delete --> Test
    
    Test -->|No| Debug[디버깅 및 수정]
    Debug --> RepoCheck
    
    Test -->|Yes| Deploy[배포]
    Deploy --> End([완료])
    
    style Start fill:#51cf66,stroke:#2f9e44,color:#000
    style Migration fill:#ffd43b,stroke:#fab005,color:#000
    style RepoCheck fill:#ffd43b,stroke:#fab005,color:#000
    style Test fill:#ffd43b,stroke:#fab005,color:#000
    style End fill:#51cf66,stroke:#2f9e44,color:#000
```
